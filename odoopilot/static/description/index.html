Your team uses Odoo.
Without logging in to Odoo.

Every employee gets an AI assistant on Telegram or WhatsApp. They apply for leave, approve requests, log timesheets and update the CRM by typing or speaking, in 15 languages. No Odoo login, no app to install, no training.

100% free LGPL-3 open source Self-hosted Odoo 17 & 18 Community

One message, one tap. The leave request exists in Odoo.

Should you install this?

Yes, if
✓ Half your team avoids the Odoo UI
✓ Approvals and CRM updates sit for days
✓ Field or warehouse staff need Odoo on a phone
✓ You self-host and want your data to stay put
✓ You already have an LLM key, or want a free tier
No, if
✗ You want a bot for customers, not staff
✗ You are on Odoo Online, which cannot install custom modules
✗ You cannot expose an HTTPS webhook endpoint
✗ You want zero AI in your ERP under any circumstances

Built for people who do not trust a chatbot with an ERP

This is the part most AI addons skip.

🔒 Their own permissions
Each chat user is an Odoo user. Record rules and access rights apply unchanged. The bot cannot surface anything they could not already open.
✅ Every write asks first
Reads run immediately. Writes stage the change, name the resolved record and wait for a Yes. The button carries a per-write nonce, so an injected instruction cannot swap the record between question and tap.
📜 Immutable audit log
One row per tool call, read or write, filterable by user, tool, channel and outcome. Nothing the assistant does is invisible.

Running in about 15 minutes

1. Install
Drop the module in your addons path and install it from Apps.
2. Configure
Settings → OdooPilot. Paste a bot token and an LLM key, click Register webhook.
3. Link users
Each employee sends /link once and confirms in Odoo. Done.
You will need: a self-hosted Odoo 17 or 18 Community instance reachable over HTTPS, a Telegram bot token (free) or a Meta WhatsApp Cloud API account, and an LLM API key (Groq and Ollama cost nothing). Optional Odoo modules unlock more tools: HR, Expenses, Timesheets, Calendar, Stock.
